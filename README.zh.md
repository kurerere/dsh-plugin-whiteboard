# dsh-plugin-whiteboard

[English](./README.md)

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）Web/桌面客户端插件：右侧栏里的
**AI 画板**。它属于当前对话——你在对话里说想画什么，模型就在这块画板上画出来，2D 用 canvas，3D 用
three.js，并在回答还在进行时一笔一笔地出现。

## 它长在哪

画板不是另一个聊天窗口，而是**这个对话的画布**：

- 三个画板工具注册在**主智能体**上。所以直接在中间的输入框说「画一张三步的登录流程图」，它就会画——
  不用打开任何面板。
- 右侧栏标签（`Ctrl+Shift+B` → 新建标签 → **画板**）是这块画板的显示端。打开它不会新建会话，也不会
  另起一段上下文。
- 标签底部只有**把面板放全屏时**才出现输入框（那时中间输入框被面板盖住了）；它发的就是这个对话的消息。
  并排停靠时没有这行——一个对话只该有一个输入框，多一个就多一处你自己都不知道打给谁的字。

## 怎么用

1. 照常说话，比如「画一棵故障排查的决策树」「用 3D 搭一个小台灯」「把这个对话画成时间线」。
2. 想看过程就打开右侧栏的画板标签：图形分批出现，而不是最后一次性刷出来。
3. 想改就继续说：「把第三个框改成红色」「右边再加一个分支」——模型按 id 更新已有图形，而不是整块重画。

画板上方是一行状态条：图形或物体计数、**撤销**、**导出**、**清空**；只有两面都画了东西时，左边才会多出一个
`2D` / `3D` 切换。

- **自动选面**：模型只画了一面（绝大多数情况）时，画板就显示那一面，不问你选哪面——清空 3D 也不会让一张有
  2D 图形的板看起来是空的。两面都有内容时，`2D` / `3D` 才会出现，默认跟着模型最后画的那一面。
- **撤销**：退回上一批图形，用状态条上的按钮或 `Ctrl+Z`（焦点不在输入框里时）。**清空**也能撤销。
- **清空**：点两次确认，只清当前这一面。
- **导出**：把当前这一面存成 PNG（2D 画布或 3D 的一帧）。

插件不添加其它按钮：右侧栏标签是唯一入口。

## 行为

- **属于对话**：画板文档按会话 id 保存在 Host 上，画板工具就是主智能体的工具。所以画图和读文件、跑命令
  一样出现在对话记录里，也和水面下的上下文一致——「把刚才讨论的架构画出来」无需任何额外说明。
- **画完自己露面**：一个对话里第一次画东西时，右侧栏会自己打开画板（只在那一次；之后你自己决定看不看，
  它不会反复抢你的面板）。返回一个已经有图的对话不会触发。
- **边画边看**：画板文档存在 Host 上，工具每调用一次就更新并落盘；浏览器在标签可见时轮询（模型回答进行中
  更密，约 350ms 一次），所以你会看到图形分批出现。
- **持久**：画板存在 `<dsh home>/storages/whiteboard/<sessionId>.json`，刷新页面、重启 Host 后仍在；
  2D 和 3D 两面各自保存。
- **升级不丢图**：从 0.1.x（画板自带聊天的那一版）升级后，旧画板文档会一次性迁移到它所属的对话上；
  已经有画板的对话不会被覆盖，旧文件保留不删。
- **子智能体不画板**：委派出去的子智能体看不到这三个工具，它们该干活而不是画图。

## 代价（说清楚）

这份能力不是免费的，有两个固定成本：

| | |
|---|---|
| **上下文税** | 三个工具声明 + 一段绘制规范常驻**每个**主会话请求：合计 **8,460 字符**（工具声明 5,461 + 规范 2,999），约 2.3k token，画不画都要付。工具声明初版是 10,088 字符，已裁到 5,461，并且 `scripts/face-budget.test.mjs` 把上限钉住了，防止以后悄悄变大。稳定前缀仍可被提示缓存复用，实际成本低于字面值。 |
| **同一时间线** | 画图和其它工作是同一个智能体、同一条时间线上的事，不能并行。让它画板，就是让它先做这件事。 |

## 画板工具

| 工具 | 作用 |
|---|---|
| `whiteboard_draw` | 向 2D 画布追加一批操作：`add` / `update` / `remove` / `clear` |
| `whiteboard_3d` | 向 3D 场景追加一批对象操作，以及可选的视图（相机、灯光、阴影、背景、网格、自动旋转） |
| `whiteboard_read` | 读出完整状态：每个形状/物体的几何与材质、相机、灯光、视口和诊断 |
| `whiteboard_look` | 把打开的画板面板截成图片，并返回测量与警告；`overlay: 'ids'` 标出元素 id，`debug: 'shadow-only'` 只看阴影通道 |
| `whiteboard_api` | 实时契约：工具/字段说明、默认值、调色板、当前相机与灯光、视口、限制、示例 |

模型只能通过 `whiteboard_look` 看到画面：只有画板 tab 在屏幕上时才可能取帧。每次改动在面板打开时也会顺带
请求一张小图；`whiteboard_read` 不需要面板。GUI 本身有 token 围栏——浏览器不是画板的取景器。

2D 坐标是一个固定的逻辑方框 `0..1000`（原点左上、y 向下），按面板等比缩放；3D 是世界单位、y 向上、地面在
`y=0`。支持 7 种 2D 图元（矩形、椭圆、线、箭头、折线、SVG path、文本）和 6 种 3D 图元（立方体、球、圆柱、
圆锥、圆环、平面），颜色优先使用会随主题解析的调色板 token（`blue`、`amber`、`ink`、`muted` …），因此
浅色/深色主题下都成立。

## 安装

包内附带构建好的 `lib/`：

```sh
dsh plugin --profile desktop add github:kurerere/dsh-plugin-whiteboard
```

重启 DeepSeek Harness 后加载插件。Web 配置请把 `--profile desktop` 换成
`--profile web`，然后启动 `dsh --profile web`。
卸载：`dsh plugin --profile desktop remove dsh-plugin-whiteboard`。

## 开发

```sh
pnpm install
pnpm run check        # 类型检查 + 构建 lib/ + 生成类型 + 校验产物与线上契约 + 文档模型/预算回归测试
```

独立开发/验证（不改动你的桌面配置）：

```sh
node scripts/dev.mjs setup     # 建一个隔离的 DSH_HOME（.wbdev）并把本仓库 link 进去
node scripts/dev.mjs start     # 起一个独立的 Host（默认 57090，不打开浏览器）
node scripts/e2e.mjs           # Playwright 冒烟：主输入框画图 → 标签显示 → 撤销/导出/清空
node scripts/dev.mjs stop
```

设计说明（含“为什么画板状态不放在会话日志里”的取证）见 [notes/design.md](notes/design.md)。

开发脚本在 Windows / macOS / Linux 上都能跑：系统相关的那几件事（用哪个 shell、哪个进程占着端口、
进程还在不在、怎么结束进程树）只集中在 `scripts/platform.mjs`，两个分支由 `scripts/platform.test.mjs`
覆盖，也进了 `pnpm run check`。`scripts/e2e.mjs` 用你机器上已有的 Playwright，不额外装一个：机器上没有
时把 `WBDEV_PLAYWRIGHT_DIR` 指向一个 `playwright-core` 包。

## 已知限制

- 画板文档存在 Host 的 storages 目录里，不写进会话日志：它不随会话分叉走——分叉一个新对话，画板是空的。
- 撤销历史存在 Host 内存里（每块画板最近 12 步），Host 重启后只能撤销重启之后的改动，画板本身仍在。
- **导出** 保存当前这一面（2D 画布或 3D 的一帧），不会把两面拼在一起。
- 图形数量有上限（2D 300 个、3D 120 个对象）；超出时工具会拒绝这一批并给出提示，而不是静默丢弃最早的图形。
- 文本使用系统字体栈渲染，不做换行排版以外的富文本（不支持富格式、图片、嵌入内容）。
- 浅色主题下，绿色、琥珀色这类**小字**对比度偏低：它们是 dsh 自己的静态强调色，画板不去改它们，否则同一块板会和界面徽章不一致。需要更强对比时让模型用 `ink` / `muted`（浅色下已提到 AA 级别）。
- 浏览器在标签可见时每秒数次轮询画板状态；这是本地环回请求，不产生模型费用。
- 画板属于**主对话**：子智能体看不到画板工具，所以它画的图只能由主智能体来画。
